# MOTORSPORT EMPIRE — VISION DU PROJET

## 1. Concept

Motorsport Empire est une simulation de management de sport automobile
se déroulant dans un univers entièrement fictif.

Le joueur ne commence pas à la tête d'une équipe dominante.

Il doit construire progressivement son organisation jusqu'à pouvoir,
s'il réussit, créer un véritable empire du sport automobile.

L'expérience doit pouvoir s'étendre sur plusieurs décennies.


## 2. Philosophie principale

Une récompense doit avoir de la valeur parce que le joueur a dû
comprendre, décider, prendre des risques et parfois échouer pour l'obtenir.

Le jeu ne doit pas être basé sur une simple succession de boutons
"acheter une amélioration".

Chaque grande réussite doit être la conséquence de plusieurs systèmes
interconnectés.


## 3. Réalisme

Le jeu recherche un réalisme de simulation et de décision.

Le réalisme ne doit cependant pas devenir une accumulation de tâches
administratives inutiles.

Le joueur doit prendre les décisions importantes.

Les employés et départements s'occupent du travail correspondant
à leurs responsabilités.


## 4. Information imparfaite

Le joueur ne connaît pas directement toutes les valeurs réelles
du moteur de simulation.

Il reçoit les informations disponibles pour son organisation.

Exemples :

- potentiel estimé d'un pilote ;
- performance estimée d'une pièce ;
- prévisions météorologiques ;
- informations sur les concurrents ;
- fiabilité estimée ;
- données issues des essais.

La qualité des employés, outils et infrastructures influence
la précision de ces informations.


## 5. Monde vivant

Le monde doit pouvoir fonctionner sans le joueur.

Les équipes contrôlées par l'IA doivent :

- recruter ;
- licencier ;
- négocier ;
- développer leurs voitures ;
- effectuer des essais ;
- changer de stratégie ;
- gérer leurs finances ;
- signer des sponsors ;
- investir dans leurs infrastructures ;
- changer de fournisseurs ;
- réussir ou échouer.

Des équipes peuvent progresser, décliner ou disparaître.

De nouvelles organisations peuvent apparaître.

Les pilotes et employés vieillissent, progressent, changent d'équipe
et prennent leur retraite.


## 6. Construction de l'empire

Le joueur peut commencer avec une petite structure disposant
de moyens limités.

À long terme, son organisation peut développer :

- une équipe de course ;
- un département de recherche ;
- des infrastructures avancées ;
- une académie de pilotes ;
- un département moteur ;
- une activité de constructeur ;
- plusieurs équipes ;
- plusieurs programmes automobiles.

Le rôle du joueur évolue avec la taille de son organisation.

Une petite équipe peut être gérée directement.

Un grand groupe nécessite progressivement de déléguer certaines
responsabilités à des directeurs.


## 7. Écurie cliente vers constructeur

Une équipe ne devient pas constructeur en appuyant simplement
sur un bouton.

Cette transformation nécessite notamment :

- investissements ;
- infrastructures ;
- recrutement ;
- technologies ;
- recherche ;
- moyens de fabrication ;
- bancs d'essai ;
- développement ;
- validation ;
- fiabilité.

Un constructeur peut éventuellement fournir ses technologies
ou moteurs à d'autres équipes.


## 8. Recherche et développement

Une nouvelle pièce ne représente pas simplement un bonus de performance.

Son développement comprend plusieurs étapes possibles :

Concept
→ conception
→ simulation
→ CFD
→ soufflerie
→ fabrication
→ essais
→ analyse
→ validation
→ évolution.

La performance réelle d'une pièce peut être différente
de la performance prévue.


## 9. Essais

Les essais constituent une partie importante du développement.

Le jeu doit notamment permettre :

- essais hivernaux ;
- essais libres ;
- programmes de corrélation ;
- tests aérodynamiques ;
- tests de fiabilité ;
- longs relais ;
- comparaison A/B ;
- programmes pneumatiques ;
- programmes de réglages.
Les essais doivent produire des données que le joueur doit interpréter.

Le jeu ne doit pas révéler automatiquement la conclusion parfaite
d'un programme d'essais.

Les données peuvent notamment concerner :

- chronos et mini-secteurs ;
- dégradation des pneus ;
- températures ;
- vitesse de pointe ;
- comportement dans différents types de virages ;
- consommation ;
- fiabilité ;
- comparaison entre spécifications ;
- corrélation entre simulation et piste ;
- feedback des pilotes.

La quantité et la qualité des données déterminent le niveau
de confiance des conclusions.

Les conditions de piste, la météo, les pneus, le carburant,
le pilote et l'évolution du circuit peuvent compliquer
l'interprétation d'une comparaison.

Les compétences du personnel et la qualité des outils d'analyse
doivent aider le joueur à comprendre ces données sans lui révéler
directement toutes les valeurs cachées de la simulation.
Le temps de piste est limité.

Le joueur doit donc choisir ce qu'il souhaite apprendre.


## 10. Concepts automobiles

Le développement de la voiture de la saison suivante commence
avant la fin de la saison actuelle.

Plusieurs philosophies techniques peuvent être étudiées.

Un nouveau concept peut présenter :

- avantages ;
- inconvénients ;
- risques ;
- potentiel ;
- problèmes de corrélation ;
- difficultés de développement.

Un concept radical peut échouer.


## 11. Évolution visuelle de la voiture

Les modifications techniques importantes doivent être visibles
sur le modèle de la voiture lorsque cela est pertinent.

Exemple :

un nouvel aileron avant doit pouvoir avoir une géométrie différente
de l'ancien.

Le joueur doit pouvoir comparer différentes spécifications.

Exemples :

SPEC A
contre
SPEC B.

À terme, les voitures de différentes saisons doivent pouvoir conserver
leur apparence historique.


## 12. Pilotes

Les pilotes possèdent plusieurs caractéristiques et comportements.

La vitesse pure n'est qu'une partie de leur valeur.

Exemples :

- qualifications ;
- rythme de course ;
- régularité ;
- gestion des pneus ;
- pluie ;
- attaque ;
- défense ;
- feedback technique ;
- adaptation ;
- expérience ;
- comportement sous pression.

Le potentiel réel peut être caché au joueur.


## 13. Personnel

Les employés sont des individus.

Ils peuvent :

- progresser ;
- recevoir des offres ;
- négocier ;
- changer d'équipe ;
- obtenir des promotions ;
- prendre leur retraite.

Une personne recrutée jeune peut passer plusieurs décennies
dans la même organisation.


## 14. Marché et négociations

Les contrats ne doivent pas fonctionner comme :

"Salaire demandé : 3 000 000"
"3 000 000 proposé"
"ACCEPTÉ".

Une négociation peut porter sur :

- salaire ;
- durée ;
- primes ;
- statut ;
- options ;
- clauses ;
- objectifs ;
- projet sportif.

Plusieurs organisations peuvent négocier simultanément avec
la même personne.

Les agents peuvent avoir leurs propres comportements.


## 15. Sponsors

Les sponsors sont des entreprises fictives possédant leurs propres
objectifs et budgets.

Les négociations peuvent concerner :

- durée ;
- montant ;
- emplacement ;
- visibilité ;
- exclusivité ;
- résultats attendus ;
- bonus.

La réputation et les performances de l'équipe influencent
son attractivité commerciale.


## 16. Éditeur de livrée

Le joueur peut construire l'identité visuelle de son équipe.

Le système doit progressivement permettre de personnaliser :

- couleurs ;
- motifs ;
- finition ;
- numéros ;
- logo de l'équipe ;
- logos des sponsors ;
- positionnement des sponsors.

La livrée doit apparaître sur la voiture en course ainsi que
dans les autres présentations pertinentes.


## 17. Simulation des courses

Le résultat d'une course ne doit pas être déterminé à l'avance
puis simplement animé.

La course doit être réellement simulée.

Elle prendra progressivement en compte :

- caractéristiques du circuit ;
- voiture ;
- pilote ;
- pneus ;
- carburant ;
- météo ;
- température ;
- trafic ;
- dépassements ;
- défense ;
- stratégie ;
- fiabilité ;
- incidents ;
- arrêts aux stands.


## 18. Intelligence artificielle

L'IA ne doit pas connaître magiquement les valeurs cachées
de la simulation.

Elle doit prendre des décisions à partir des informations
dont son équipe dispose.

L'IA stratégique doit pouvoir :

- analyser les pneus ;
- anticiper les arrêts ;
- tenter un undercut ;
- tenter un overcut ;
- réagir aux adversaires ;
- analyser la météo ;
- modifier son plan ;
- gérer ses deux voitures.

Les pilotes IA doivent pouvoir :

- attaquer ;
- défendre ;
- préparer un dépassement ;
- gérer leurs ressources ;
- prendre différents niveaux de risque ;
- adapter leur comportement à leur adversaire.


## 19. Replay

La simulation doit produire suffisamment de données pour permettre
la reconstruction des événements importants.

Le système de replay doit progressivement permettre :

- retour sur un événement ;
- différentes caméras ;
- ralenti ;
- sauvegarde d'événements historiques.

Les événements majeurs d'une ancienne saison pourront éventuellement
être revus plusieurs années plus tard.


## 20. Présentation audiovisuelle

Le jeu doit donner de l'importance aux grands moments.

La présentation pourra comprendre :

- présentation du circuit ;
- présentation de la grille ;
- introduction de course ;
- réalisation TV ;
- replays ;
- pole position ;
- victoire ;
- podium ;
- titre pilotes ;
- titre constructeurs ;
- événements historiques.

Les cinématiques doivent utiliser les voitures, pilotes, équipes
et résultats de la sauvegarde.

## 33. Retransmission des séances

Les essais libres et qualifications doivent pouvoir être suivis
comme une véritable retransmission automobile.

Un réalisateur virtuel analyse les événements de la séance
et décide quelles voitures sont intéressantes à montrer.

Il peut notamment détecter :

- secteurs violets ;
- meilleurs secteurs personnels ;
- tours rapides ;
- amélioration importante ;
- bataille pour la pole ;
- pilote menacé d'élimination ;
- dernière tentative ;
- sortie de piste ;
- incident ;
- problème mécanique ;
- nouvelle spécification intéressante ;
- événement inhabituel.

L'importance d'un événement dépend de son contexte.

Un secteur violet pendant Q3 dans les dernières secondes doit avoir
beaucoup plus d'importance qu'un secteur violet au début d'un
programme d'essais libres.

Le joueur peut utiliser :

- réalisation automatique ;
- suivi d'un pilote ;
- sélection manuelle des caméras.

Les informations de chronométrage doivent être produites directement
par la simulation.

La retransmission observe et présente la simulation :
elle ne crée pas artificiellement les événements.
## 21. Presse

Le monde contient plusieurs médias fictifs.

Ils peuvent publier :

- actualités ;
- résultats ;
- analyses ;
- rumeurs ;
- transferts ;
- informations techniques ;
- critiques.

Les médias ne disposent pas nécessairement d'informations parfaites.

Une rumeur peut être correcte, imprécise ou fausse.


## 22. Conférences de presse

Certaines situations importantes peuvent déclencher
une conférence de presse.

Les réponses du joueur peuvent influencer :

- relations ;
- réputation ;
- employés ;
- pilotes ;
- sponsors ;
- perception médiatique.

Le jeu ne doit pas afficher directement toutes les conséquences
sous forme de "+5 / -5".

Les déclarations importantes peuvent être conservées
et rappelées ultérieurement.


## 23. Histoire

Chaque sauvegarde doit progressivement produire sa propre histoire.

Le jeu conserve notamment :

- champions ;
- résultats ;
- records ;
- anciennes équipes ;
- anciennes voitures ;
- pilotes ;
- grandes victoires ;
- grandes défaites ;
- transferts importants ;
- évolution du groupe du joueur.

À long terme, un musée ou système d'archives permettra
de consulter cette histoire.


## 24. Univers fictif

Les équipes, pilotes, constructeurs, sponsors et championnats
principaux sont fictifs.

Cela permet au monde du jeu de développer sa propre identité
et sa propre histoire.

L'univers ne doit pas être une simple copie de la Formule 1.


## 25. Règle fondamentale de développement

La simulation est prioritaire sur sa représentation graphique.

Une course doit pouvoir fonctionner correctement sans rendu 3D.

Les graphismes, animations, replays et cinématiques représentent
les événements produits par la simulation.

Ils ne déterminent pas artificiellement leurs résultats.


## 26. Objectif émotionnel

Le joueur doit pouvoir se souvenir de moments comme :

"notre première pole",

"notre première victoire",

"la saison où notre nouveau concept a échoué",

"le jeune pilote que nous avons découvert",

"notre premier moteur",

"notre premier championnat",

"le jour où nous sommes devenus constructeur".

La réussite doit être difficile à obtenir pour qu'elle soit
réellement satisfaisante.
## 27. Circuits et diversité

Les circuits doivent avoir une véritable identité et ne pas être
de simples variations visuelles d'un même tracé.

L'univers pourra contenir notamment :

- circuits urbains ;
- circuits permanents modernes ;
- anciens circuits historiques ;
- circuits très rapides ;
- circuits techniques ;
- circuits étroits ;
- circuits larges favorisant les dépassements ;
- circuits avec forts dénivelés ;
- circuits sollicitant fortement les pneus ;
- circuits exigeants pour les freins ;
- circuits favorisant l'efficacité aérodynamique ;
- circuits favorisant la puissance moteur.

Chaque circuit possède ses propres caractéristiques.

Une voiture dominante sur un circuit peut être moins performante
sur un autre.

Le calendrier doit obliger les équipes à développer une voiture
capable de fonctionner dans des conditions variées.

Les circuits peuvent également évoluer au fil des décennies :
modifications du tracé, resurfaçage, nouvelles infrastructures,
changements de sécurité et éventuellement arrivée ou disparition
de certaines épreuves.


## 28. Nouvelle génération de pilotes

Le monde doit continuellement produire de nouvelles générations
de pilotes.

Les nouveaux pilotes ne doivent pas apparaître soudainement
à l'âge adulte avec une simple note de performance.

Ils doivent avoir une histoire sportive simulée avant d'atteindre
les catégories importantes.

Le monde junior pourra comprendre plusieurs niveaux fictifs :

Karting
→ formules juniors
→ catégories régionales
→ catégories internationales
→ catégorie reine.

Tous les jeunes pilotes ne suivront pas le même parcours.

Certains progresseront rapidement.

Certains manqueront de financement.

Certains resteront plusieurs saisons dans une catégorie.

Certains changeront de discipline.

Certains talents ne réussiront jamais à atteindre le plus haut niveau.


## 29. Académie de jeunes pilotes

Une organisation suffisamment développée peut créer sa propre
académie de pilotes.

L'académie ne doit pas simplement fournir un bonus de développement.

Le joueur peut notamment :

- rechercher de jeunes talents ;
- financer leur carrière ;
- choisir les championnats dans lesquels ils évoluent ;
- suivre leurs performances ;
- financer des essais ;
- leur fournir du coaching ;
- les placer dans des équipes partenaires ;
- leur donner des séances d'essais ;
- les promouvoir dans une catégorie supérieure ;
- décider de continuer ou arrêter leur soutien.

Le recrutement comporte une incertitude.

Un jeune pilote très performant à un niveau inférieur ne deviendra
pas automatiquement un champion.

Les recruteurs fournissent une estimation de son potentiel,
de ses qualités et de ses faiblesses.


## 30. Filière de formation

Une grande organisation peut progressivement construire une
véritable filière.

Exemple :

Académie
→ équipe junior partenaire
→ équipe de catégorie intermédiaire
→ pilote de réserve
→ équipe principale.

Le joueur peut également négocier avec des équipes indépendantes
pour placer ses pilotes.

Les équipes contrôlées par l'IA disposent elles aussi de systèmes
de détection et peuvent entrer en concurrence avec le joueur
pour recruter les meilleurs jeunes talents.


## 31. Histoire générationnelle

Sur une sauvegarde de plusieurs décennies, différentes générations
de pilotes doivent apparaître.

Un jeune pilote découvert par le joueur peut progressivement devenir :

pilote junior
→ espoir
→ titulaire
→ vainqueur
→ champion
→ vétéran
→ retraité.

Certains anciens pilotes pourront éventuellement continuer leur
carrière dans le sport automobile dans d'autres fonctions adaptées.

L'objectif est que le joueur développe un attachement à l'histoire
des personnes qu'il a accompagnées.
## 32. Pays, régions et identité des circuits

Le monde possède différents pays et régions.

Un pays ne doit pas être représenté uniquement par un nom et un drapeau.

Les circuits doivent pouvoir refléter la géographie, le climat
et l'identité visuelle de leur région.

Les environnements peuvent notamment comprendre :

- montagnes ;
- vallées ;
- forêts ;
- campagnes ;
- zones méditerranéennes ;
- déserts ;
- côtes ;
- grandes plaines ;
- environnements tropicaux ;
- villes ;
- zones industrielles.

Deux circuits situés dans le même pays peuvent néanmoins avoir
des environnements et des caractéristiques très différents.

La localisation peut influencer notamment :

- température ;
- probabilité de pluie ;
- humidité ;
- vent ;
- altitude ;
- évolution de la piste ;
- apparence de l'environnement.

Les circuits fictifs doivent sembler appartenir à leur région
sans être de simples copies de circuits réels.
« Direction artistique de l'interface » indiquant : moderne, épurée, premium, sombre, très lisible, couleur de l'écurie comme accent, informations complexes présentées progressivement et animations sobres.
